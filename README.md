# Симулятор магазина — файл для скачивания

Скачайте `shop-simulator.html` и откройте его в браузере с подключением к интернету (Three.js загружается с CDN). Для управления на компьютере кликните по сцене, затем ходите на WASD и смотрите мышью; E — продать товар. На телефоне используйте левый джойстик для движения, правый — для обзора, кнопку E — для взаимодействия.

Файл: [скачать игру](./shop-simulator.html)

Это компактная браузерная демо-версия. Для запуска через локальный сервер можно использовать `npx vite --host 0.0.0.0`.
